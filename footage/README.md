# footage/ — gravações do jogo para os reels de montagem

Gravações de tela de partidas reais do Navistron (celular ou computador), usadas nos reels de montagem. O render
(`scripts/render.mjs`) corta só os trechos que cada post pede (`templates/montage.js`). O índice de cada gravação, com os
segundos das provocações, dos boosts e das explosões, fica no `MONTAGEM.md`, na raiz do repositório.

- Para subir pelo site do GitHub: abrir esta pasta, Add file → Upload files (até 25 MB por arquivo).
- Não editar nem apagar um vídeo depois que algum post o usar.
- Gravação nova: avisar na conversa; a rotina mede os tempos e cria a seção dela no índice antes de usar.
